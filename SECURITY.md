# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through [GitHub's vulnerability reporting](https://github.com/torsher-app/torsher/security/advisories/new) with the version, what an attacker can do and how to reproduce it.

You'll get an answer within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

## Supported versions

Fixes go into the latest release. Update with `docker compose pull && docker compose up -d`.
