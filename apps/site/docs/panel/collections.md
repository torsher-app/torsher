# Collections

A collection is your own list of titles, like “Holidays” or “With kids”, shared by all profiles on the server. <Ui k="panel.nav.collections" /> is where you create and set them up. Titles are added on the TV.

::: tip What you'll learn
How to create a collection, put it on the TV home screen, hide it from some profiles, and add and remove titles.
:::

## Create a collection

1. Select <Ui k="panel.collections.add" />.
2. Enter a <Ui k="panel.collections.dialog.name" />, up to 60 characters. Two collections can't have the same name.
3. Turn on <Ui k="panel.collections.dialog.showOnHome" /> to add a row to the showcase home screen. The row appears once the collection has titles.
4. Under <Ui k="panel.collections.dialog.visibleTo" />, uncheck the profiles that shouldn't see it. They won't see it on the home screen or in <Ui k="nav.mine" />.
5. Select <Ui k="panel.collections.dialog.submit" />.

## Add titles

On the TV, hold OK on a poster and select <Ui k="actions.collections" />. See [Mine](/docs/watch/mine).

## The list

Each row shows the collection's name, how many titles it has, <Ui k="panel.collections.onHome" /> if it is on the home screen, and which profiles it is hidden from.

Click a collection to see its titles. <Ui k="panel.collections.removeTitle" /> next to a title takes it out of the collection.

## Change or delete a collection

In the menu of a row, or at the bottom of an open collection:

- **<Ui k="panel.collections.edit" />** opens the same settings as when creating it: the name, the home screen row and the profiles.
- **<Ui k="panel.common.delete" />** removes the collection. Its titles stay in the catalog and in profile lists.
